# viniciuscodes-theme

Este é o tema WordPress oficial do meu blog pessoal, [viniciuscodes.com.br](https://viniciuscodes.com.br).

Originalmente desenvolvido para uso estritamente pessoal, decidi torná-lo público caso alguém queira usar como referência, estudar a estrutura ou se inspirar para seus próprios projetos de blog pessoal/minimalista. :)

---

## ✨ Destaques do tema

- **Minimalista e Focado em Texto**: Tipografia e layout pensados para máxima legibilidade e conforto visual (utiliza [Atkinson Hyperlegible Next](https://www.brailleinstitute.org/freefont/) autohospedada localmente).
- **Zero Requisições de Terceiros**: Proteção ativa contra CDNs externas de fontes (Google Fonts, Adobe, Typekit), priorizando privacidade e desempenho.
- **Leve e Rápido**: Sem inchaço de frameworks pesados, bibliotecas JS desnecessárias ou builders visuais.
- **Funcionalidades Nativas**:
  - Blogroll dedicado com suporte a favicons customizados;
  - Árvore retrátil de arquivos por ano e mês;
  - Seções de recomendação de leitura;
  - Feed RSS otimizado e estrutura semântica limpa.

---

## 🚀 Instalação

1. Clone ou baixe este repositório:
   ```bash
   git clone https://github.com/ViniciusMarti/viniciuscodes-theme.git
   ```
2. Coloque a pasta na pasta de temas do seu WordPress:
   ```
   wp-content/themes/viniciuscodes
   ```
3. Ative o tema através do painel do WordPress em **Aparência > Temas**.
